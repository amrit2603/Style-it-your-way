# Demonstration inputs

The four original, fictional AI-created garment/model photos and PDF are in [demo](../demo/ASSETS.md). They are reusable sample inputs, not real customer photos or evidence of personalized fidelity. No Panna photography is copied.

Run `scripts/start.ps1 -Demo -Platform` to populate the separate demonstration database. Its catalog and generated results are visibly labelled fixed samples; samples cannot be ordered. To test ordering, create a priced product in the admin panel, confirm its original, generate, review and publish it.

Use the admin Photo library to add stock-model and room photos that you have permission to reuse. Uploaded files stay in private local storage. A room-placement test requires a transparent PNG product cutout. Room placement is a labelled CPU demonstration, not measured interior design.

Real shopper photos belong in their private session, never in this folder or Git. Signing out, deletion and expiry revoke access. Do not add downloaded photos without checking reuse rights.
