# Demonstration asset provenance

The four fictional garment images were generated with the built-in ImageGen tool on 20 November 2026 and copied into the project. They are not Panna photos, real inventory or evidence of FASHN quality. They seed only the labelled demonstration catalog. Live mode has a separate merchant-uploaded catalog. `catalog-example.pdf` is a four-page PDF made from these images for import testing.
