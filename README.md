# VYUMI Style It Your Way

Baseline discovery started on 20 November 2026. This workspace contains requirements and reference findings; it is not yet a runnable application.

- [Requirements and open decisions](docs/BASELINE.md)
- [Observed reference design](docs/reference/DESIGN.md)
- [Council review](docs/COUNCIL.md)
- [Draft Octopus sitemap](https://octopus.do/lms7ug459of)

The requested feature has a merchant workspace for uploading garments, generating catalog imagery, reviewing it and publishing it, plus a shopper storefront with personal virtual try-on. Paid APIs are allowed. The user selected a local Next.js + FastAPI prototype. Provider selection and detailed product behavior remain open.

Merchant inputs are individual garment photos and PDF catalogs. The [product design](docs/superpowers/specs/2026-11-20-style-it-your-way-design.md) is approved. The [implementation plan](docs/superpowers/plans/2026-11-20-style-it-your-way.md) is ready for review and execution-method selection. Application code has not started.
